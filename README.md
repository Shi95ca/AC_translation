# Автоматический перевод учебных карточек студентов (XLS/XLSX -> DOCX)

Инструмент для автоматизации перевода русскоязычных учебных карточек студентов (выгрузка из АИС «Студент», лист `CartSt`) на английский язык с сохранением официальной альбомной верстки для иностранного отдела факультета.

Программа берет исходный файл `.xls` или `.xlsx`, пропускает скрытые служебные строки выгрузки, переводит дисциплины по утвержденному словарю факультета (с автоматическим обращением к онлайн-переводчику для новых спецкурсов, МФК и тем курсовых работ), определяет курс и инспектора учебной части и формирует готовый к печати и заверению документ Microsoft Word (`*_EN.docx`).

---

## Основные возможности

* **Точное сохранение макета и полей:** генерация выполняется путем XML-клонирования таблиц из эталонного шаблона `template.docx` (альбомная ориентация A4, фиксированная ширина столбцов, колонтитул `Translated from Russian`, неразрывные заголовки семестров).
* **Гибридный конвейер перевода дисциплин:**
  1. Встроенный словарь базовых общефакультетских курсов и образовательных модулей (`Module "Mathematics"`, `Module "General Physics"` и др.).
  2. Официальная база спецкурсов в файле `courses1.txt` (более 1700 дисциплин).
  3. Каскадный онлайн-переводчик для новых дисциплин и тем курсовых работ (не требует API-ключей) с автоматическим сохранением новых переводов в локальный словарь `custom_courses_cache.tsv`.
* **Учет всех особенностей выгрузки АИС «Студент»:**
  * автоматическая фильтрация скрытых шаблонных строк на листе `CartSt`;
  * удаление служебных колонок («Пересдачи», «Примечание») и номеров мобильных телефонов из домашнего адреса;
  * транслитерация ФИО, номеров групп и адресов по стандарту ИКАО/ГОСТ;
  * автоматическое формирование раздела **`Extracurricular courses`** при наличии блока «Дополнительно сдано».
* **Гибкая настройка без правки кода:** список инспекторов курсов хранится в текстовом файле `inspectors.txt`, а заверительная подпись начальника иностранного отдела считывается напрямую из нижней части `template.docx`.

## Состав репозитория

| Файл | Назначение |
| :--- | :--- |
| `translate_card.py` | Основной скрипт парсинга Excel и сборки переведенного документа Word |
| `run_windows.bat` | Скрипт запуска в один клик для Windows (сам создает `venv` и ставит пакеты) |
| `template.docx` | Обезличенный эталонный шаблон Word (каркас таблиц, полей, колонтитулов и подписей) |
| `sample_card.xlsx` | Демонстрационная учебная карточка на условного *Иванова Ивана Ивановича* для проверки |
| `courses1.txt` | База утвержденных переводов дисциплин (формат `Русское название [TAB] Английское название`) |
| `inspectors.txt` | Редактируемая база инспекторов учебной части по курсам |
| `prepare_github_files.py` | Служебная утилита очистки метаданных шаблона и перегенерации `sample_card.xlsx` |
| `custom_courses_cache.tsv` | Автоматически создаваемый кэш новых переводов (появляется после первого нового курса) |

## 1. Установка с нуля

### Вариант А. Установка на Windows 10 / 11

Для работы программы на компьютере должен быть установлен Python версии 3.9 или новее. Все остальные библиотеки скрипт установит сам.

1. **Скачайте Python:**
   Перейдите на официальный сайт [https://www.python.org/downloads/](https://www.python.org/downloads/) и нажмите желтую кнопку **Download Python 3.x.x**.
2. **Установите Python (важный шаг!):**
   Запустите скачанный установщик. **Обязательно поставьте галочку внизу окна `Add python.exe to PATH`** и только после этого нажмите **Install Now**.
3. **Скачайте этот репозиторий:**
   * На странице проекта на GitHub нажмите зеленую кнопку **`<> Code`** -> **`Download ZIP`**.
   * Распакуйте скачанный архив в любую удобную рабочую папку (например, `Документы\Перевод_карточек`).
4. **Первый запуск и автоустановка пакетов:**
   Дважды кликните по файлу **`run_windows.bat`**.
   * При самом первом запуске батник автоматически найдет Python, создаст внутри папки изолированное окружение `venv` и скачает три необходимые библиотеки (`python-docx`, `xlrd`, `openpyxl`). Для этого шага нужен интернет.
   * При всех последующих запусках установка пропускается, и программа открывается мгновенно.

> **Если Windows SmartScreen выдает предупреждение при запуске `.bat`:** нажмите *«Подробнее»* (*More info*) -> *«Выполнить в любом случае»* (*Run anyway*).

---

### Вариант Б. Установка на Linux (Ubuntu / Debian / Mint / Fedora / Arch)

1. **Установите Python 3, модуль виртуальных окружений и `tkinter` (для графического диалога выбора файлов):**

   *Ubuntu / Debian / Linux Mint:*
   ~~~bash
   sudo apt update
   sudo apt install -y python3 python3-venv python3-pip python3-tk git
   ~~~

   *Fedora / RHEL:*
   ~~~bash
   sudo dnf install -y python3 python3-pip python3-tkinter git
   ~~~

   *Arch Linux / Manjaro:*
   ~~~bash
   sudo pacman -S python python-pip tk git
   ~~~

2. **Клонируйте репозиторий и создайте виртуальное окружение:**
   ~~~bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd <ПАПКА_РЕПОЗИТОРИЯ>
   python3 -m venv venv
   source venv/bin/activate
   pip install --upgrade pip
   pip install python-docx xlrd openpyxl
   ~~~

## 2. Быстрый старт на готовом обезличенном примере

В репозитории уже лежат очищенный шаблон **`template.docx`** и демонстрационная карточка **`sample_card.xlsx`** (на вымышленного студента 4-го курса *Иванова Ивана Ивановича*), поэтому проверить работу инструмента можно сразу после скачивания:

1. Запустите программу:
   * **Windows:** двойной клик по `run_windows.bat`.
   * **Linux:** выполните в папке проекта `./venv/bin/python translate_card.py`.
2. В консоли отобразится список найденных Excel-файлов в папке:
   ~~~text
   Найденные Excel-файлы в папке:
     [1] sample_card.xlsx
     [A] Перевести ВСЕ файлы из списка
     [O] Выбрать другой файл через Проводник
   ~~~
3. Нажмите **`Enter`** (по умолчанию выберется пункт `[1]`).
4. Скрипт покажет карточку студента и автоматически определенного инспектора 4-го курса, после чего задаст два вопроса:
   * **`Какую дату с оригинала справки поставить в конце?`** — введите дату штампа с бумажного русского оригинала (например, `05.11.2026`) или просто нажмите `Enter` для подстановки сегодняшней даты.
   * **`Инспектор [Enter = N.A. Nesterova, либо введите курс 1-6 или ФИО]:`** — нажмите `Enter`, чтобы оставить автоопределенного инспектора.
5. Рядом с исходным файлом появится готовый документ **`sample_card_EN.docx`**. Откройте его в Word или LibreOffice: в нем будут заполнены анкета, приказы, два семестра, переведенная тема курсовой работы, секция `Extracurricular courses`, таблица штампа учебной части и подпись начальника иностранного отдела.

## 3. Режимы повседневной работы с реальными карточками

* **Перетаскивание мышкой (Drag-and-Drop в Windows):** выделите в Проводнике один или сразу несколько файлов `.xls` / `.xlsx` (в любых папках) и перетащите их на значок `run_windows.bat`. Готовые файлы `*_EN.docx` будут сохранены рядом с каждым исходником.
* **Пакетный перевод всей папки:** положите полученные из учебной части файлы `.xls` в папку со скриптом, запустите `run_windows.bat` и введите латинскую или русскую букву **`A`** — программа по очереди переведет все карточки.
* **Выбор через диалоговое окно:** введите букву **`O`** в меню запуска, чтобы выбрать файлы через стандартное окно открытия файлов операционной системы.
* **Запуск из командной строки (Windows / Linux):**
  ~~~bash
  python translate_card.py путь/к/карточке1.xls путь/к/карточке2.xlsx
  ~~~

## 4. Настройка базы инспекторов (`inspectors.txt`)

В выгрузках Excel на листе `CartSt` фамилия инспектора курса отсутствует (штамп ставится в учебной части на бумажном оригинале). Поэтому скрипт определяет курс студента автоматически в следующем порядке приоритета:
1. По последнему приказу в блоке `Приказы` (курс, на который зачислен или переведен студент).
2. Если приказов нет — по номеру старшего закрытого семестра в карточке.
3. По первой цифре трехзначного номера академической группы (например, `402б` -> 4 курс).
4. Для магистрантов (если в шапке карточки указана магистратура) используются ключи `mag1` и `mag2`.

Соответствие курсов и фамилий хранится в файле **`inspectors.txt`**, который можно редактировать в обычном Блокноте:

~~~ini
# Формат: Курс = Инициалы и Фамилия (можно писать на английском или на русском)
1 = N.O. Ivanova        # Иванова Наталья Олеговна (1 курс)
2 = N.A. Barsukova      # Барсукова Наталья Алексеевна (2 курс)
3 = V.V. Karminskaya    # Карминская Виктория Владимировна (3 курс)
4 = N.A. Nesterova      # Нестерова Наталья Александровна (4 курс)
5 = I.V. Khomulo        # Хомуло Ирина Вадимовна (5 курс)
6 = T.S. Nesterenko     # Нестеренко Татьяна Сергеевна (6 курс)
mag1 = T.S. Nesterenko  # 1 курс магистратуры
mag2 = T.S. Nesterenko  # 2 курс магистратуры
~~~

**Удобные особенности:**
* Если на курсе сменился инспектор, вы можете вписать его в `inspectors.txt` как латиницей (`A.B. Petrova`), так и **просто по-русски полностью** (`Петрова Анна Борисовна`) — скрипт сам сформирует инициалы и выполнит транслитерацию (`A.B. Petrova`).
* Если конкретную справку подписал другой инспектор (например, во время отпуска основного сотрудника), менять файл не обязательно: просто введите номер другого курса (`1`–`6`) или ФИО замещающего сотрудника прямо в ответ на запрос в консоли при генерации.

## 5. Замена начальника иностранного отдела и редактирование `template.docx`

Нижний заверительный блок перевода **не зашит намертво в код**, а считывается скриптом напрямую из конца файла **`template.docx`**.

### Как поменять ФИО начальника иностранного отдела (или название подразделения)

1. Откройте файл **`template.docx`** в Microsoft Word или LibreOffice Writer.
2. Прокрутите документ в самый низ (сразу под таблицу с полями `Inspector of the Academic Department` и `-seal of Academic Department...`), где расположен текст заверения:
   ~~~text
   I certify this is an accurate translation of the document
   Evgeny Kurov
   International Relations Office
   Faculty of Physics, MSU
   ~~~
3. Замените имя, должность или название факультета на нужные вам (при необходимости можно добавить или убрать строки в этом блоке ниже таблицы инспектора).
4. Сохраните `template.docx` (`Ctrl + S`) и закройте редактор.

При следующем запуске `translate_card.py` автоматически скопирует ваш обновленный блок заверения во все генерируемые карточки и приведет его шрифт к единому стандарту документа (`Times New Roman`, 11 пт).

### Памятка: что в `template.docx` менять можно, а что нельзя удалять

Чтобы скрипт безошибочно находил таблицы и клонировал разметку, соблюдайте следующие правила при редактировании `template.docx`:

* **Верхний колонтитул (`Translated from Russian`):** можно редактировать текст, но не меняйте параметры полей страницы, если хотите сохранить штатную вместимость таблиц.
* **Первая таблица (анкета студента):**
  * *Можно менять:* любые примеры данных во 2-м столбце (`Ivanov Ivan` и др.).
  * *Нельзя удалять:* строки и столбцы таблицы, а также английские названия полей в 1-м столбце (`Family name...`, `Date of birth...` и т.д.) — они переносятся в итоговый файл как есть.
* **Таблица 1-го семестра (прототип таблиц успеваемости):**
  * *Обязательно оставить:* саму таблицу 1-го семестра со строкой заголовка (`Name of course | Total hours | ...`) и **минимум одной строкой любого предмета под ней**. Скрипт использует первую строку предмета как эталон ширины ячеек и рамок для всех семестров и блока `Extracurricular courses`.
* **Нижняя таблица (подпись и печать учебной части):**
  * *Можно менять:* текст названия печати в средней ячейке (но обязательно сохраните в нем слово **`seal`**) и должность слева (сохранив слово **`Inspector`**).
  * *Нельзя удалять:* саму таблицу и ключевые слова `Inspector` и `seal` — по ним программа находит правые объединенные ячейки, куда вписывает ФИО инспектора курса и дату штампа.

## 6. Словарь дисциплин (`courses1.txt`) и самообучающийся кэш

При переводе каждого предмета скрипт проверяет источники в следующем порядке:
1. Обрабатывает префиксы модулей (`Модуль "..."`) и курсовых работ (`КР ...`), а также суффиксы `(часть 1/2)` и `(на английском языке)`.
2. Ищет название дисциплины в `courses1.txt` и в локальном кэше `custom_courses_cache.tsv`.
3. Если дисциплина встретилась впервые (новый спецкурс, МФК или тема курсовой работы), отправляет запрос в онлайн-переводчик, вставляет перевод в документ и дописывает пару `Русское название [TAB] Английский перевод` в файл **`custom_courses_cache.tsv`**.

Если вы хотите поправить автоматический перевод какого-либо нового спецкурса или темы курсовой, просто откройте `custom_courses_cache.tsv` в Блокноте или Excel, отредактируйте английский вариант после символа табуляции и сохраните файл. При повторной генерации карточки скрипт сразу возьмет вашу выверенную формулировку без обращения к сети.

## 7. Защита персональных данных при работе с Git

Реальные выгрузки `.xls`/`.xlsx` из учебной части содержат персональные данные студентов (ФИО, даты рождения, домашние адреса, телефоны и оценки).

* В репозитории настроен файл `.gitignore`, который блокирует индексацию всех рабочих файлов `*.xls`, `*.xlsx` (кроме демонстрационного `sample_card.xlsx`), готовых переводов `*_EN.docx` и папки `venv/`.
* Никогда не переименовывайте реальную карточку студента в `sample_card.xlsx`. Если вам нужно обновить шаблон из нового образца Word и гарантированно очистить скрытые метаданные автора документа (`docProps/core.xml` и `docProps/app.xml`), выполните:
  ~~~bash
  python prepare_github_files.py путь_к_новому_образцу.docx
  ~~~
